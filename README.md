# Tomte

> [!WARNING]
> **Very experimental.** I'm building Tomte around my own dotfiles setup
> first, and it currently assumes a lot of it (chezmoi + a git remote +
> 1Password, one repo, macOS on Apple silicon). The goal is to make it
> great for everyone, but in its current state I don't recommend using
> it yet — expect sharp edges, breaking changes, and opinionated
> defaults.

A quiet macOS menubar app that keeps your dotfiles from drifting.

Tomte watches the files [chezmoi](https://chezmoi.io) manages and notices
when the copy on disk stops matching the source of truth — because a program
rewrote its own config, because you edited the source on another machine,
because a template re-rendered differently. Drift shows up in the menubar;
one click reviews the diff, and a three-pane merge editor (source / last
written / on disk) resolves the cases where both sides moved. Every apply is
journaled and undoable.

Named after the Scandinavian household gnome who tends the home while you
sleep — which is what the daemon does.

## How it works

- **`tomte`** — the menubar app (GPUI). Dashboard, review pane, merge editor.
- **`tomted`** — the daemon. Watches the source repo and every managed
  target, scans for drift, fetches origin, journals history to SQLite, and
  serves the app over a Unix socket (ndjson protocol, `crates/proto`).
- Template-aware: lines generated by chezmoi templates are protected from
  write-back and marked in the merge editor with the template line on hover.

## Status

v0 — built for my own dotfiles first. macOS 13+, Apple silicon.

## Building

```sh
cargo build --workspace          # binaries: target/debug/{tomte,tomted}
cargo test --workspace
./scripts/bundle.sh              # assembles target/bundle/Tomte.app
```

Releases are signed, notarized, and published by CI on version tags
(see `docs/RELEASING.md`).
